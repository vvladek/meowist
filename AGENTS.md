# Project Rules

## General

- This project uses Expo SDK 54. When you're unsure about an Expo API or the task depends on SDK-specific behavior, consult the versioned Expo SDK 54 documentation https://docs.expo.dev/versions/v54.0.0/ before writing any code.
- Read project documentation only if it exist and when relevant to the current task.
- Do not inspect node_modules, dist, build or .git unless explicitly requested.
- Read only files relevant to the current task.
- Keep context minimal.
- Ask before making large architectural changes.
